# World generation: second investigation slice

The seed hash is independently implemented in Rust and matches eight native UTF-16 vectors, including empty, odd/even length, non-ASCII, surrogate-pair and embedded-NUL cases. The installed hash uses two wrapping 32-bit accumulators initialized to 5381; it stops at NUL and combines them using 1566083941. Seed LabTerrain1 resolves to 1121644293.

The installed Meadows height-combination arithmetic is reproduced in Rust with explicit Float32/Float64 conversion points. All 512 controlled samples match the native result exactly, including the local terrain area and a wider coordinate grid. This verifies arithmetic before river carving and after it. Base heights, five Perlin outputs and river results are **native oracle inputs**, not independently generated by Rust. The probe is intentionally separate from the playable terrain loader. No claim of full world-generation completion is made.

An important verified dependency: both DUtils.PerlinNoise overloads ultimately invoke UnityEngine.Mathf.PerlinNoise; the Double overload casts coordinates to Float32 first. The algorithm is native in this build, not implemented in the managed wrapper. A generic Perlin implementation cannot be assumed equivalent. 1,024 native positive/negative-coordinate noise samples are retained for testing candidate implementations. Unity random state also determines generator offsets and river/stream seeds; those must be reproduced before seed parity is complete. For this reference seed offset3 is -938 and generator version is 2.

The source implementation is playable-world/worldgen_probe.rs. Check-Worldgen.ps1 builds and compares against the current successful private reference. Diagnostic WorldgenCheck.cs gathers checkpoints using reflection on the installed private generator methods, behind -lab-worldgen in the marked isolated copy. It constructs a new reference generator without opening a user world. The current cache is private-cache/worldgen/native-20261016-140053-9681636; native-current.txt selects it. Data, extracted IL, logs and hashes remain private. Installed build hashes were rechecked before inspection. No dependencies were added and no executable was modified.

Evidence is under evidence/worldgen-002: game-build check, WorldGenerator/DUtils/StringExtensionMethods managed IL, native runtime log and comparison.log. The unsuccessful Perlin managed-type lookup is retained: that guessed type was not found and was not used as evidence. The independent hash and formula comparisons passed with zero difference. The gameplay build remains on its verified native-generated terrain cache; no unverified generator replaced it.
